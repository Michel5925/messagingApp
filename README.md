Full-Stack Messaging App

A full-stack private messaging application built with JavaScript, Node.js, Express, MongoDB and Mongoose.

Users can create accounts, securely log in, send private messages, manage their own messages, track unread messages and become members. The application also includes a role-based Admin Dashboard for managing users and memberships.

Features

User registration and login
Password hashing with bcrypt
Session-based authentication
Private one-to-one messaging
Edit and delete messages
Message timestamps
Unread message notifications
Last message previews
Automatic message refreshing
Membership system
Admin dashboard with role-based access control
Responsive desktop and mobile design
Server-side validation and protected routes
Centralized error handling

Technologies

Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB, Mongoose
Authentication: bcrypt, express-session
Tools: Git, GitHub, npm
